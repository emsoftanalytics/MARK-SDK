# Code of Conduct

## Our pledge

We want MARK to have a community where everyone can participate — regardless
of experience level, background, or identity. Be welcoming, be patient, and
assume good faith.

## Expected behavior

- Be respectful in issues, PRs, and discussions.
- Critique code and ideas, not people.
- Help newcomers — everyone's first PR is scary.
- Accept that maintainers make final calls on scope and direction.

## Unacceptable behavior

- Harassment, insults, or discriminatory language.
- Publishing others' private information.
- Sustained disruption of discussions.

## Enforcement

Violations can be raised through GitHub repository moderation channels, such
as issues, discussions, or maintainer review on the relevant thread. If a
report includes private safety concerns, use GitHub's private reporting tools
where available. Maintainers may edit, remove, or reject contributions and
comments that violate this code, and may ban repeat offenders.

Adapted from the spirit of the Contributor Covenant (v2.1).
